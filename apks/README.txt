Taruh file APK TikTok dan SnackVideo di folder ini.

Contoh isi folder apks\:
  - tiktok.apk
  - snackvideo.apk

Cara mendapatkan APK resmi:
  1. Jalankan download-apks.bat (dari folder utama proyek)
  2. Browser akan membuka halaman resmi TikTok & SnackVideo
  3. Unduh versi Android (.apk) dari sana
  4. Simpan / geser file .apk ke folder ini

Setelah file .apk sudah ada di sini, jalankan install-apks.bat
untuk memasangnya ke emulator.
