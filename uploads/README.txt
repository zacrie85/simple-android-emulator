Folder ini untuk mode upload otomatis.

Cara pakai:
  1. Jalankan watch-uploads.bat (biarkan jendelanya terbuka)
  2. Copy/paste video (.mp4, .mov, .mkv, .avi, .webm) ke folder ini
  3. Dalam 5 detik video otomatis dikirim ke galeri emulator,
     lalu dipindah ke subfolder terkirim\

Alternatif lebih cepat (tanpa folder ini):
  Klik kanan video di Windows Explorer -> "Kirim ke Emulator"
  (aktifkan dulu lewat add-explorer-menu.bat)

File sent-log.txt mencatat semua video yang sudah terkirim.
